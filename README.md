🔐 Cifra de César – Criptografia em Python

Este projeto implementa a clássica Cifra de César, permitindo criptografar e descriptografar mensagens através do deslocamento das letras no alfabeto.
O usuário informa o texto e o número de posições de deslocamento, e o programa retorna o resultado automaticamente.

✨ Funcionalidades

Criptografia de textos

Descriptografia

Suporte a letras maiúsculas e minúsculas

Interface simples pelo terminal

▶️ Como usar

Execute o script Python.

Escolha se deseja criptografar ou descriptografar.

Digite sua mensagem.

Informe o deslocamento desejado.

💡 Exemplo
Texto: "Hello"
Deslocamento: 3
Resultado: "Khoor"

🧠 Sobre o projeto

Feito para estudo de lógica, manipulação de strings e conceitos básicos de criptografia clássica.
